# MIDRAMO_SALES_ANALYSIS

# PROJECT TOPIC: Sales_Analysis  

## PROJECT OVERVIEW
This is an end-to-end Excel analytics project which aims to generate 
insights on the transactional sales data.By analysing the data and 
generate insights that the various parameters in the data received we
seek to gather enough insight to make reasonable decisions which then
enables us to tell compelling stories about our data from the insight
gotten and to know the best performance of our data.  


Goal: Give MidRamo Stores Inc. — a 3-branch electronics retailer — a 
single view of sales performance across regions, staff, products, and 
time, so leadership can spot trends and top/bottom performers at a glance.
